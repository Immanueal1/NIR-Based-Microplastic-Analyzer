# Security Policy

## Portfolio Showcase Security Scope

This repository is a **public proof-of-work portfolio showcase** demonstrating system engineering, mechanical prototyping, and optical machine learning performance.

- Underlying source code, backend API scripts, training pipelines, and binary model artifacts are **not stored in this repository**.

## Reporting a Security Vulnerability

If you discover a security issue or privacy concern regarding any visual asset, documentation file, or metadata in this showcase repository:

To report a problem with this repository, open an issue on GitHub. Include a description of the flagged asset, file path, and exact nature of the concern.
