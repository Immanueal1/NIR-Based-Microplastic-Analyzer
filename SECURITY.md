# Security Policy

## Portfolio Showcase Security Scope

This repository is a **public proof-of-work portfolio showcase** demonstrating system engineering, mechanical prototyping, and optical machine learning performance.

- Underlying source code (`.ino`), backend API scripts, training pipelines, and binary model artifacts (`.pkl`) are **not stored in this repository**.
- All IP addresses, Wi-Fi SSIDs, and local network configurations displayed in UI screenshots or photographs have been audit-verified and obscured to prevent metadata exposure.

## Reporting a Security Vulnerability

If you discover a security issue or privacy concern regarding any visual asset, documentation file, or metadata in this showcase repository, please report it privately:

1. **Email:** Contact the maintainer directly at [krishnakantgarhe@gmail.com](mailto:krishnakantgarhe@gmail.com).
2. **Details:** Include a description of the flagged asset, file path, and exact nature of the concern.
3. **Response Expectation:** Vulnerability and privacy inquiries will be acknowledged within **48 hours**.

Please do not open public GitHub issues for security or privacy concerns.
