# Contributing Guidelines

Thank you for your interest in the **NIR-Based Microplastic Analyzer** repository!

## Portfolio Repository Scope

This repository serves as a **public engineering portfolio and research showcase**. As such:

- **Source Code Contributions:** Pull requests attempting to add source code, firmware files, or private model artifacts are not currently accepted.
- **Documentation & Typo Fixes:** Pull requests correcting typos in documentation, fixing broken asset links, or improving accessibility are welcome!

## How to Contribute Improvements

1. **Opening an Issue:** If you notice a broken link, rendering issue, or documentation typo, please open a GitHub Issue using the provided templates.
2. **Submitting a Pull Request:**
   - Fork the repository.
   - Create a feature branch (`git checkout -b doc/fix-readme-link`).
   - Commit your documentation fix (`git commit -m "Fix broken link in README"`).
   - Push to your branch and open a Pull Request.
