# 🔬 NIR-Based Portable Microplastic Analyzer

Portable AI-powered environmental sensing device for near-infrared polymer signature classification.

---

## 📌 Features

- **Hardware:** ESP32 MCU, AS7263 6-channel NIR spectral sensor, SSD1306 OLED display.
- **Edge ML Pipeline:** SVM, Random Forest, and CNN experiments in Python with 95%+ polymer classification accuracy.
- **Form Factor:** Compact handheld hardware for field-ready environmental monitoring.
