# Changelog

All notable changes to the **NIR-Based Microplastic Analyzer** portfolio showcase repository will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to semantic documentation standards.

## [1.0.0] - 2026-08-02

### Added
- **Flagship Documentation:** Enterprise-grade documentation featuring system architecture, operational pipelines, dual UI interfaces, machine learning evaluations, and academic citation metadata.
- **Visual Performance Charts:** High-resolution result figures including overlaid NIR spectral fingerprints (`spectral_signature_overview.png`), 2D PCA cluster separability (`class_separability_pca v2.png`), per-channel bar grids, and correlation heatmaps.
- **Reference Spectral Signatures (`charts_v2/`):** Spectral curves for PET, PE, PP, PS, and PVC.
- **Video Demonstration Suite (`Live Recordings/`):** 4 MP4 video recordings demonstrating hardware operation, sensor data streaming, and web dashboard UI.
- **Portfolio Documentation Files:** Added `LICENSE`, `NOTICE`, `CITATION.cff`, `SECURITY.md`.
- **Academic Research Documentation:** Embedded official IRJMETS publication certificate (`certificate of Publication.pdf`) and compiled PDF chart reports.
- **Dataset Audit Workbook:** Included public aggregate dataset summary spreadsheet (`docs/NIR_Dataset_Excel_Summary.xlsx`).
